## Milestone steps

- Milestones now have **steps** with a status (Planned, In Progress, Done, Paused, Abandoned). Done and Abandoned steps need an end date, and steps must lie inside the milestone dates.
- Steps run in **parallel stages**: steps in the same stage run together, and stages run in sequence. You can edit them from an editable steps graph, add steps in a modal, or join a stage or open a new one.
- Every milestone gets a read-only **Shelf** step that always comes first. Tasks without a chosen step go there.
- **Milestone and step templates** are available per project, and new projects get defaults. Create a milestone from a template, and the dates are spread over its stages.
- The create and edit milestone pages are split into **Basic Information** and **Steps** tabs. After you create a milestone, you can open its steps right away.
- Tasks now belong to a step. Pick the step when you create or edit a task, plan a milestone's tasks in its steps, and see the milestone and step as separate badges everywhere tasks are shown.
- The task list has a new **Steps** filter.
- The project home page shows step progress as labelled bars, with parallel steps stacked. Capacity bars are blue below 100%, green at 100% and red above.
- Steps are included in export and import, along with the step and milestone templates.
- The MCP server has new tools for steps and templates, and the task tools take a step.

## Gantt charts

- A new editable Gantt chart of the steps appears on the create milestone and milestone steps pages. It has a status badge and task progress for each step, parallel steps are bordered, and the current day is marked in red.
- The name column is sticky and resizable, and fits its content.
- The Percentages Gantt bars show the percentage in their label.

## Dates and tasks

- Dates are marked with start, due and end emojis. Duration and days left badges appear on tasks, milestones and project home. The period of a milestone summary is shown as start and end date badges.
- **Won't do** is now a terminal task status next to Done.
- The Timebox UI is temporarily hidden.
- Table filters are more compact, stay open when an option reloads the page, and have group headings with select and deselect links.

## Frontend preview mode

- The frontend can now run without a backend, with all data kept in the browser's localStorage. It comes with demo data and a "Reset preview data" action.
- There is a new demo data seeder app for the backend, which shares its data with the preview.

## Fixes

- American dates now show as "Nov 2, 2026" and the date picker accepts the format it writes.
- "1 day left" no longer reads "1 days left".
- Gantt charts no longer fail to draw after their component is removed, and the name column refits correctly.
- Desktop: inline styles apply again.
- The login email defaults to `admin@email.com`.
