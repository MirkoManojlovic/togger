## Tasks

- Setting several tasks to **Done** or **Won't do** at once now asks for the end date and lets you add log entries, the same as closing a single task.

## Desktop app

- The desktop app now **checks for an update on startup**, and the update check reports a failure as "Failed" in the settings.

## Export and import

- Importing a project now applies its changed fields (icon, description, work days) to the existing project when the imported copy is newer. Before, the import check showed the project as out of sync and an import did nothing.
- The import check now compares project members by content, so identical members are no longer reported as different.

## MCP server

- The demo data now includes the `mcp` account.
