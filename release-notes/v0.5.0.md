## Backend status

- A new **Backend status** page (also reachable from the login page, no login needed) shows the version and state of the backend and the MCP server.
- In the desktop app, the backend and the MCP server are started with the app, stopped when it exits, and checked every minute. A sidecar that is down is started again, and one that runs another release than the app is restarted.
- The page has the buttons **Start All**, **Stop All** and **Restart All** to control both in the desktop app.

## Tasks

- You can **archive** and **unarchive** the selected tasks in the task list. Archived tasks have a badge in the task list and in the timebox and milestone step task lists, and the **show archived** choice stays in the URL.
- A closed task has a **Reopen** button in the edit task page. Reopening a task now clears its end date.
- Task links accept any address scheme except unsafe ones. Imported tasks with a link address that is not allowed are rejected.

## Export and import

- The import and export settings have a **directory selector** to pick the folder (desktop app).
