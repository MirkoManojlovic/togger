## Project home

- The active tasks board has two new columns, **Done** and **Won't do**, with the tasks that are not archived.
- The member names on the board are centered.

## Team daily and slacker

- Tasks with the status **Done** or **Won't do** are now included in the team daily and the slacker.
- **Choose tasks** is now a board like the one on the project home: a column for each status, and in the team daily a row for each member with buttons to select or unselect all of their tasks. Tasks you unselect are dimmed, and a task already logged today has a blue border.

## Interface

- Cards and bordered boxes have a **shadow**, and shadows are stronger in the dark theme so they can be seen.
- The priority badge in the quick task creation shows the priority code (p1 to p5) instead of the priority name.
