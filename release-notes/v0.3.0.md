## Export and import

- **Deletions now travel with the export.** Deleting a task or a log entry is recorded, and an import deletes it from the other side too, unless it was changed after the deletion. The import asks for confirmation before it deletes anything.
- The export/import check shows two new statuses: **pending delete** (deleted on disk, still in the database) and **deleted** (deleted in the database, still on disk). The import results show deleted and skipped entries.
- Task labels are now replaced by the newer set on import, so a swapped label is no longer added next to the old one.
- The import check now matches project labels by name and accounts by email, and ignores the project id, organization and timestamps, so identical data is no longer reported as different.

## Sync

- A new **sync button** in the navbar imports and exports all projects at once and shows the results in tabs.
- The app now **syncs automatically** at the interval set in the settings (default 60 s) and checks every 30 seconds whether something is pending, shown as a dot on the button.
- The sync interval in the settings is saved with a **Save** button instead of on every keystroke.

## Tasks

- A task can now be **deleted** from the edit task page.
- The end date badge is shown right after the due date badge in the other task views, and the days left badge is hidden for tasks that have an end date.

## Log entries

- A log entry can now be **deleted** with a delete button, together with all its versions.
- The date, status and created by badges are aligned in all log entry views.

## Editor

- The rich text editor now supports **undo and redo** (including the redo shortcuts) and keeps formatting when replacing text.

## Interface

- The sidebar icons stay on the left and the labels fade in after the expand animation ends.

## Other

- The default admin account is now named "Admin Account".
- Extra spaces were removed from the default task template lists.
